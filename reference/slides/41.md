# deck.spec.md Is the Planning Schema

Seven sections define intent before a single slide is written.

<v-clicks>

- **Meta** — title, purpose, audience, tone, target-length, style-preset
- **Source Materials** — documents digested to produce the deck (project decks only)
- **Through-Line** — the conceptual thread: type, concept, and which slides it surfaces in
- **Design Tokens** — colors, typography, spacing, motion as semantic variables
- **Layout System** — preferred builtins, custom layouts, components, CSS files
- **Slides** — per-slide kind, layout, title, body, notes, and source citations
- **Notes Policy** — optional presenter notes guidelines and asset rules

</v-clicks>
