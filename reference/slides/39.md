# Every Deck Ships With Seven Scaffold Files

Generated by `new-deck.sh`, present in every deck.

<v-clicks>

- **setup/shortcuts.ts** — Registers `?` (help overlay) and `p` (presenter mode) keyboard shortcuts
- **composables/useHelp.ts** — Reactive `showHelp` state shared between shortcuts and the help component
- **components/KeyboardHelp.vue** — Full-screen shortcut overlay using `--deck-accent` and `--deck-font-*` tokens
- **global-top.vue** — Mounts KeyboardHelp when `showHelp` is true
- **global-bottom.vue** — Footer with slide number and title, hidden on cover/end layouts
- **setup/mermaid-renderer.ts** — Beautiful Mermaid rendering with deck palette tokens injected automatically
- **styles/transitions.css** — 12 cinematic CSS transitions imported by `styles/index.css`

</v-clicks>
