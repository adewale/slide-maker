# Seven Scripts Catch Problems Before the Audience Does

Scaffolding, validation, and comparison.

<v-clicks>

- **new-deck.sh** — Scaffold a complete deck from any preset with all 7 scaffold files
- **deck-lint.mjs** — Validate structure, overflow, sources, and quality against compiler rules
- **style-audit.mjs** — Audit CSS token usage across decks for hardcoded hex values
- **deck-preview.mjs** — Quick text preview of slide content without launching the dev server
- **deck-diff.mjs** — Diff two versions of a deck to show what changed between iterations
- **compare-decks.mjs** — Side-by-side comparison of multiple decks for inconsistencies
- **build-and-verify.sh** — Full build pipeline with post-build checks as the final gate

</v-clicks>
