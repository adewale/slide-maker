# Code Block Titles

Add `[filename]` after the language to show a title bar.

```ts [tokens.css]
:root {
  --deck-bg: #0c0e14;
  --deck-fg: #e4e8ef;
  --deck-accent: #22d3ee;
}
```

```go [main.go]
func main() {
    http.HandleFunc("/", handler)
    log.Fatal(http.ListenAndServe(":8080", nil))
}
```
