# Planet CF

A 9-slide deck presenting [Planet CF](https://github.com/adewale/planet_cf), a feed aggregator built on Cloudflare's Python Workers platform.

## Through-line

"What happens when Python wakes up inside JavaScript's house?" -- the deck traces the architectural consequences of running Python inside V8 via Pyodide/WASM, culminating in the boundary layer pattern that makes it work.

## Running

```bash
npm install
npx slidev
```

## Building

```bash
npx slidev build
```

## Style

Uses the `cloudflare` preset with warm cream background, Cloudflare orange accent, and Inter typography.
