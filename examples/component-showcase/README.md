# Component Showcase

Demonstrates every supported slide kind, built-in layout, and interactive Slidev feature. Each slide adopts the color palette of a real project from the skill-maker collection.

## Run

```bash
npx slidev component-showcase/slides.md
```

## Build

```bash
npx slidev build component-showcase/slides.md --base /component-showcase/ --out _build/component-showcase
```
