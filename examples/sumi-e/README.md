# The Garden (sumi-e)

A philosophical narrative about Garten, rendered in the sumi-e ink-wash style.

## Style preset
`sumi-e` — contemplative, spacious, austere

## Fonts
- Display: Zen Old Mincho
- Body: Crimson Pro
- Mono: JetBrains Mono

## Custom components
- `BrushDivider.vue` — SVG brush stroke divider with ink texture
- `EnsoCircle.vue` — imperfect circle with brush texture filter
- `InkWash.vue` — radial gradient wash backgrounds

## Custom layout
- `ZenSlide.vue` — extreme padding, 60% max-width, asymmetric offset

## Global layer
- `global-bottom.vue` — faint paper texture gradient

## Dev
```bash
npx slidev --port 3039
```

## Build
Included in `bash build.sh` from project root.
