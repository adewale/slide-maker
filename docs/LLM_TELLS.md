# LLM tells

Telltale signals that a presentation was generated by an LLM. Every item here is something to actively avoid. If a compiled deck exhibits any of these, it fails review.

## Typography and color

- Inter, Roboto, or system-ui as the sole font family
- Purple-to-blue gradients on dark backgrounds (`#6366f1` → `#8b5cf6` family)
- Identical card layouts with rounded corners, soft shadows, and generous padding on every slide
- Perfect color harmony with no intentional tension — real designers break rules deliberately
- The "safe palette": slate-900 background, slate-100 text, indigo-500 accent

## Language

- Stock transitions: "Let's dive in", "In conclusion", "Without further ado", "It's worth noting", "Let's explore"
- Gerund-leading bullets: "Leveraging...", "Enabling...", "Streamlining...", "Empowering..."
- Thesis-as-slide-2: a slide that reads like an essay introduction ("In this presentation, we will...")
- Uniform bullet length: every bullet is 8-12 words — real writing has varied rhythm
- Hedging: "arguably", "it's important to note", "one might say", "it goes without saying"
- Unsupported superlatives: "revolutionary", "game-changing", "cutting-edge", "best-in-class"
- Filler preambles: "As we all know...", "In today's fast-paced world...", "The landscape is evolving..."
- Paired synonyms: "robust and scalable", "simple yet powerful", "fast and efficient"
- The "it's not X, it's Y" reframe: "It's not a limitation, it's a feature", "It's not a tool, it's a platform", "Read-only is not a limitation. It is the architecture." — LLMs reach for this structure compulsively because it sounds insightful while requiring no actual insight. The negation-then-assertion pattern is a crutch that substitutes rhetorical structure for genuine argument.

## Structure

- Agenda slide as slide 2 ("What we'll cover today")
- Exactly 3 bullets per slide, every slide
- Feature-list structure (feature → feature → feature) instead of narrative arc (tension → exploration → insight → resolution)
- Closing slide is "Thank You! Questions?" or a bare URL
- No war stories, no surprises, no counterintuitive findings — everything confirms the thesis
- Symmetric structure: if section A has 3 slides, sections B and C also have exactly 3
- "Summary" slide that restates every previous slide
- Section titles that are nouns ("Architecture", "Performance", "Security") instead of claims ("The single-threaded guarantee makes state trivial")

## Visual patterns

- No visual variety — every content slide uses the same layout
- Stock metaphor imagery: lightbulbs, handshakes, puzzle pieces, rocket ships, gears
- Mermaid diagrams that restate the text ("Request → Server → Database") instead of revealing hidden structure
- Perfect grid alignment everywhere with no intentional asymmetry
- Emoji as visual shorthand (checkmarks, rockets, sparkles, fire)
- Every diagram has 3-5 nodes in a neat left-to-right flow

## Animation and interaction

- Every bullet list is v-clicked — no editorial judgment about which lists benefit from progressive reveal
- No hover states, no spotlight patterns, no interactive elements
- Single transition type used throughout (usually `fade` or `slide-left`)
- No v-mark annotations — nothing is underlined, circled, or struck through
- Animations are uniform: same timing, same easing, same direction for everything

## Content

- Generic examples: "Company X increased revenue by 30%"
- No source citations — claims float free of evidence
- Suspiciously round numbers: 100%, 50%, 10x, "millions of users"
- Every point supports the thesis — no dialectical tension, no complications, no "however"
- Abstract nouns doing the work of concrete specifics: "improved developer experience" instead of "cut deploy time from 12 minutes to 45 seconds"
- No specificity: "a large-scale system" instead of "147 Durable Objects across 3 regions"

## Interface slop

Patterns that mark a *surface* as machine-generated, adapted for slides from
the 37-pattern taxonomy at https://impeccable.style/slop. Items already covered
above (Inter/Roboto, purple gradients, identical cards, everything centered) are
not repeated. Thresholds marked **[lint]** are enforced by `tools/deck-lint.mjs`.

### Typography slop

- Flat type hierarchy — heading and body sizes too close together. Aim for at least a 1.25 ratio between steps so the hierarchy is unmistakable.
- Overused "AI" fonts beyond Inter/Roboto: **Geist, Plus Jakarta Sans, Space Grotesk, Fraunces**. They converge across generated designs. Use a preset font unless the font is the project's actual brand identity. **[lint]** flags Inter/Inter Tight/Roboto/Arial outside brand-exception presets.
- Single font family for the whole deck — pair a distinctive display font with a refined body font.
- Monospace used to signal "technical vibes" for body copy. Reserve mono for code.
- All-caps **body** text — word-shape recognition breaks. (Small eyebrow labels in caps with tracking are fine.)
- Icon-tile-above-heading feature cards — the universal generator template.

### Color slop

- Pure black `#000000` background or text — harsh and unnatural; use a near-black. **[lint]**
- Cyan-on-dark and neon box-shadow glows — the default "cool" look.
- Defaulting to dark mode as a retreat from a real palette decision.
- Gradient text (`background-clip: text` over a gradient) — decorative, kills scannability. **[lint]**
- Gray text on colored backgrounds — looks washed out.

### Layout and space slop

- Hero-metric cliché: one big number, a small label, three supporting stats, a gradient accent.
- Monotonous spacing — the same gap everywhere, no rhythm.
- Nested cards / wrapping every element in a bordered container — visual noise.
- Line length beyond ~80 characters — fatiguing to read.
- Glassmorphism / `backdrop-filter: blur` as decoration rather than to solve a real layering problem. **[lint]**
- Justified text — rivers of whitespace. **[lint]**

### Motion slop

- Bounce/elastic easing — dated and tacky. Prefer exponential ease-out (quart/quint/expo).
- Animating layout properties (width/height) — janky. Animate `transform` and `opacity`.

### Other slop

- Tight body line height below 1.3 (use 1.5–1.7); body text below 14px; letter-spacing above 0.05em on body.
- Skipped heading levels (h1 straight to h3) — breaks the document outline.
- Redundant intros that restate the slide heading.
- Decorative sparklines that look sophisticated but carry no trend — only chart real movement.
- Amputating content on mobile because it is inconvenient (this deck system has a real mobile scroll view — use it).

## The meta-signal

A deck that looks competent but says nothing memorable. You close the tab and can't recall a single specific image, number, or story. The information was arranged correctly but never *argued* anything. There is no point of view.

## How to use this document

During compilation (COMPILER_RULES.md Phase 7: Validate), check every slide against this list. A single occurrence of a tell is a yellow flag. Three or more tells in the same deck means the deck reads as AI-generated and needs revision.

The fix is almost always the same: replace the generic with the specific. Replace the stock phrase with silence (delete it — the slide is better without it). Replace the symmetric structure with an argument. Replace the safe palette with a deliberate choice.
